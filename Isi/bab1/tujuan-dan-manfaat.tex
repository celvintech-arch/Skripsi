\subsection{Tujuan}
Tujuan dari penelitian dan perancangan aplikasi ini adalah:
\begin{enumerate}
    \item Merancang aplikasi pengarsipan data (\textit{data archiving}) otomatis dengan arsitektur \textit{Client-Worker} terdistribusi yang berkomunikasi melalui HTTP API JSON (\textit{agent.ashx}), guna memindahkan data historis mahasiswa dari basis data produksi ke basis data arsip secara terjadwal, terstruktur, dan dapat dikonfigurasi.

    \item Membangun portal \textit{web} berbasis ASP.NET yang menyediakan layanan \textit{on-demand retrieval} untuk memfasilitasi pencarian dan penarikan data historis mahasiswa lintas basis data secara fleksibel, cepat, dan aman tanpa membebani basis data produksi.

    \item Mengimplementasikan sistem antrean tugas (\textit{task queue}) menggunakan SQL Server Agent dan skrip PowerShell pada mesin eksternal terpisah guna menjalankan eksekusi pemindahan data secara terpenjadwal tanpa membebani infrastruktur server utama Pusdatin UNTAR.
\end{enumerate}

\subsection{Manfaat}
Manfaat yang diharapkan dari hasil penelitian ini antara lain:
\begin{enumerate}
    \item \textbf{Bagi Pusdatin UNTAR}: Meningkatkan performa eksekusi kueri operasional harian dan efisiensi ruang penyimpanan pada basis data produksi melalui pemisahan dan pengurangan beban akumulasi data historis yang sudah tidak aktif.

    \item \textbf{Bagi Sistem dan Infrastruktur}: Mempercepat proses pencadangan data (\textit{backup process}) secara signifikan, karena ukuran basis data produksi aktif yang telah terarsipkan menjadi lebih kecil dan lebih efisien untuk dicadangkan secara berkala.

    \item \textbf{Bagi Layanan Akademik dan Audit}: Memudahkan dan mempercepat staf operasional dalam memenuhi kebutuhan penarikan data historis mahasiswa saat diperlukan untuk keperluan pelaporan regulasi, pemeriksaan internal, maupun audit eksternal universitas.
\end{enumerate}
